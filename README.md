# sysadmin-test-task
System Administrator Test Task — Linux, Networking, VPN, Proxmox

## 1. Linux и настройка сети

В VirtualBox была развернута виртуальная машина Ubuntu Server.

Основной сетевой интерфейс:

- Interface: enp0s3
- Static IP: 192.168.10.200/24
- Gateway: 192.168.10.1
- DNS: 8.8.8.8, 1.1.1.1

Для настройки сети использовался Netplan.

Конфигурационный файл находится в:

network/00-installer-config.yaml

### VLAN

На физическом интерфейсе enp0s3 были созданы два VLAN-интерфейса:

- VLAN 10 — 192.168.110.1/24
- VLAN 20 — 192.168.120.1/24

VLAN позволяют логически разделять одну физическую сеть на несколько изолированных сетевых сегментов.

Например, VLAN 10 может использоваться для рабочих станций сотрудников, а VLAN 20 — для камер видеонаблюдения или другого оборудования.

Если сервер подключён к trunk-порту коммутатора, несколько VLAN могут передаваться через один физический сетевой интерфейс с использованием тегирования IEEE 802.1Q.

## 2. SSH

На Ubuntu Server установлен и запущен OpenSSH Server.

Удалённое подключение выполнялось с Windows:

ssh sysadmin@192.168.10.200

Для аутентификации была создана пара ключей ED25519.

Публичный ключ клиента был добавлен на сервер в:

~/.ssh/authorized_keys

После настройки подключение к серверу выполняется по SSH-ключу без ввода пароля.

Приватные SSH-ключи в репозиторий не добавлялись.

## 3. WireGuard VPN

На Ubuntu Server был установлен и настроен WireGuard.

VPN-сеть:

- VPN Server: 10.10.10.1/24
- Windows Client: 10.10.10.2/24
- UDP Port: 51820

Windows использовался в качестве WireGuard-клиента.

После подключения была проверена доступность VPN-сервера командой:

ping 10.10.10.1

Команда `wg` на сервере подтверждает успешный handshake и передачу данных между peer-устройствами.

В целях безопасности приватные WireGuard-ключи не публикуются.

Пример конфигурации без секретных ключей:

wireguard/wg0.conf.example

## 4. Proxmox VE

Proxmox VE был развернут в отдельной виртуальной машине VirtualBox.

Для управления использовался Web UI Proxmox.

В Proxmox:

- загружен ISO-образ Ubuntu Server;
- создана VM 100;
- выделены виртуальные CPU и RAM;
- создан виртуальный диск;
- сетевой интерфейс подключён через vmbr0;
- в качестве установочного носителя подключён Ubuntu Server ISO.

При запуске гостевой Ubuntu Server возникла техническая проблема с nested virtualization, так как схема лаборатории имеет дополнительный уровень виртуализации:

Physical PC -> VirtualBox -> Proxmox VE -> Guest VM

На физическом сервере Proxmox виртуальная машина создаётся аналогично, но без дополнительного слоя VirtualBox.

Скриншоты конфигурации Proxmox и созданной VM находятся в каталоге:
